## All the keyword research data you need, under one roof

Any keyword research solution has to answer two hard questions at scale: which keywords matter for a domain, and which of those are worth targeting. The keyword research endpoints of DataForSEO Labs API answer both, leveraging a database of more than four billion indexed keywords and over 500 million SERPs across Google's regional indexes, with sub-2-second response times for every API request.

## Three data sources in a single keyword research API

DataForSEO Labs API encompasses historical SERP data, advertising platform metrics, clickstream signals, and DataForSEO's proprietary indexes.

- Google Ads search volume, CPC, and competition data populated across the DataForSEO keyword and SERP indexes.
- DataForSEO's proprietary Keywords Database contains over 4.5 billion keywords, with historical Google Ads metrics and relevant SERP data.
- Clickstream-derived search volume, estimated traffic, and demographic info, independent of Google Ads' bucketed ranges.

## DataForSEO Labs API endpoints for keyword research

### Keywords For Site
Relies on Google Ads data and DataForSEO's proprietary SERP database to provide keywords highly relevant to a target domain. Each keyword idea in the response includes related categories plus search volume, CPC, competition, and other useful information. Supported search engine: Google.

### Keyword Suggestions
Leverages a full-text search algorithm to obtain a multitude of keywords that contain a certain search query. Positioned as an affordable way to incorporate long-tail keywords into a keyword research tool. Supported search engine: Google.

### Related Keywords
Uses Google SERP to provide up to 4,680 keyword ideas for each seed query, extracting keywords from the "searches related to" feature for each level of a specified depth. Supported search engines: Google, Amazon.

### Keyword Ideas
Looks beyond semantic similarity to provide relevant keywords by relying on the unified list of services and categories for Google Ads; detects the category of the seed keyword and returns highly relevant, non-obvious terms that are not necessarily semantically similar. Supported search engine: Google.

### Search Intent
Classifies keywords into informational, navigational, commercial, or transactional intent for up to 1,000 keywords per request. Classification is generated by an in-house model trained on labelled SERP behavior, not assigned from a static lookup table. Supported search engine: Google.

### Bulk Keyword Difficulty
Returns a proprietary 0 to 100 difficulty score for up to 1,000 keywords in a single request. The score reflects the relative difficulty of ranking in Google's top-10 organic results, calculated against the current SERP composition for each query.

### Keyword Overview
Provides all available data for a keyword: CPC, competition, search volume, search intent, plus SERP, backlinks, and clickstream data for a batch of up to 700 keywords in a single request.

### Historical Keyword Data
Provides Google historical keyword data for specified keywords, including search volume, CPC, competition values for paid search, monthly searches, and search volume trends, available since August 2021 depending on keyword/location/language combination.
