# What profile information anyone can see on Instagram | Facebook Help Center
URL: https://www.facebook.com/help/347751748650214

Certain profile information on Instagram, for public and private accounts, is always public. This information can be associated with a person and is public to everyone, on or off Instagram, even for people who don't have an Instagram account.

Profile information that anyone can see on an Instagram profile includes:

- Name
- Username
- Profile picture
- Bio
- Links
- Number of followers and following
- Avatar
- Threads username
- Channels created by the account

Keep in mind that this information can't be hidden and remains public regardless of whether the personal account is set to private or public. If the account owner doesn't want people to see this info, the only recourse Meta offers is editing the profile fields themselves (there is no privacy toggle that hides them).
